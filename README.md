# Customer Shopping Behavior Analysis

## Project Overview
This project analyzes customer shopping behavior using transactional data from **3,900 purchases across multiple product categories**. The objective is to uncover patterns in customer spending, identify key product preferences, analyze subscription behavior, and generate insights that can support data-driven business strategies.

The project integrates **SQL for querying and analysis**, **Python for Exploratory Data Analysis (EDA)**, and **Power BI for interactive dashboard visualization**.

---

## Objectives

- Analyze customer purchasing patterns
- Identify high-performing product categories
- Understand customer segmentation and demographics
- Evaluate subscription vs non-subscription purchase behavior
- Generate insights for strategic business decisions

---

## Project Workflow

### 1. Data Collection
The dataset contains **3,900 customer purchase records** including information such as:

- Customer demographics
- Product category
- Purchase amount
- Subscription status
- Payment methods
- Purchase frequency

---

### 2. Data Cleaning
Data cleaning was performed to ensure consistency and accuracy.

Tasks performed:
- Handling missing values
- Standardizing column formats
- Fixing inconsistent date formats
- Removing duplicate entries
- Validating data types

---

### 3. Exploratory Data Analysis (EDA)

EDA was performed using **Python in Jupyter Notebook** to explore patterns and relationships within the dataset.

Libraries used:
- Pandas
- NumPy
- Matplotlib
- Seaborn

Key analysis included:
- Customer age distribution
- Spending patterns by category
- Gender-based purchasing trends
- Regional purchase behavior
- Subscription vs non-subscription analysis

---

### 4. SQL Data Analysis

SQL was used to perform deeper analysis and answer business questions using structured queries.

Examples of analysis queries:

- Top selling product categories
- Average purchase amount per customer
- Customer purchase frequency
- Subscription revenue contribution
- Customer segmentation based on spending

SQL concepts used:
- Aggregations (SUM, AVG, COUNT)
- GROUP BY
- Window Functions
- CTEs
- Ranking functions

---

### 5. Dashboard Creation

An **interactive dashboard was developed in Power BI** to visualize the insights derived from the analysis.

Dashboard features include:

- Customer demographic overview
- Category-wise sales performance
- Subscription analysis
- Regional sales distribution
- Purchase behavior trends

The dashboard allows users to interactively explore the data and gain business insights.

---

## Key Insights

- Certain product categories drive the majority of sales
- Subscription customers show higher purchase frequency
- Customer demographics influence purchasing behavior
- Specific regions contribute significantly to overall revenue
